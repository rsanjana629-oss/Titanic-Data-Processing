# Titanic-Data-Processing
# Titanic Data Acquisition, Cleaning and Preprocessing

## Project Overview
This project focuses on acquiring, exploring, cleaning, and preprocessing the Titanic passenger dataset using Python.

The main objective is to identify and handle missing values, check duplicate records, examine outliers, and convert categorical data into numerical format.

## Dataset Description
- Dataset: Titanic Passenger Dataset
- Original records: 891
- File format: CSV
- Tools: Google Colab and Python

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data Acquisition
2. Exploratory Data Analysis (EDA)
3. Missing Value Detection and Handling
4. Duplicate Detection
5. Outlier Detection using Boxplots
6. Data Cleaning
7. Categorical Data Encoding
8. Final Dataset Verification

## Data Preprocessing
- Missing Age values filled using the median.
- Missing Embarked values filled using the mode.
- Duplicate records checked.
- Sex column encoded into numerical values.
- Embarked column converted using one-hot encoding.

## Final Results
- Final dataset shape: 891 rows × 12 columns.
- Missing values: 0.
- Duplicate rows: 0.

## Project Files
- `train.csv` – Original dataset.
- `titanic_cleaned.csv` – Preprocessed dataset.
- `titanic_preprocessing.ipynb` – Google Colab notebook.
- `Week1_Report.docx` – Detailed project report.
- `screenshots/` – Project execution screenshots.

## Conclusion
The Titanic dataset was successfully explored, cleaned, and preprocessed using Python. The final dataset is prepared for further exploratory analysis and machine learning applications.
